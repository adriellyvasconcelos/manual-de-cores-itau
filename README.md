# 🎨 Guia de Identidade Visual — Itaú

Este projeto apresenta um guia de identidade visual inspirado na marca Itaú, reunindo cores, tipografia, escala de fontes e exemplos de contraste para padronizar a criação de interfaces digitais.

## 📋 Sobre o projeto

O objetivo é documentar os principais elementos visuais utilizados no desenvolvimento de interfaces, garantindo consistência, legibilidade e uma identidade visual reconhecível.

O guia apresenta:

- Paleta de cores primárias e secundárias.
- Cores para temas claros e escuros.
- Cores de sucesso e alerta.
- Tipografia Poppins.
- Escala de tamanhos de fontes.
- Exemplos de contraste entre textos e fundos.

## ✍️ Tipografia

A fonte utilizada no projeto é a **Poppins**, uma tipografia moderna e adequada para interfaces digitais.

### Escala de fontes

|---|---|

### Pesos tipográficos

- Regular
- Medium
- SemiBold

## 🔍 Contraste

O guia apresenta exemplos de aplicação das cores em diferentes fundos, permitindo avaliar a legibilidade dos textos.

Os exemplos incluem:

- Texto laranja sobre fundo claro.
- Texto branco sobre fundo laranja.
- Texto laranja sobre fundo escuro.

A escolha adequada das cores e dos pesos tipográficos contribui para uma melhor experiência do usuário.
